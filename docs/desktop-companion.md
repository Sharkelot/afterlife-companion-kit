# Desktop companion status

This release does **not** include desktop-companion source code, binaries, installers, or packaging scripts. The referenced desktop app repository is private and GitHub reports no declared license (`licenseInfo: null`). No files from that repository were copied, republished, or assigned a new license for this kit.

Accordingly, v0.1.0 is a website-guide kit only. Do not describe this release as an installable desktop companion.

A future desktop release needs an explicit owner-approved license for the app source, a deliberate public source release, dependency/license review, and real platform build-and-smoke evidence. No native runtime or platform artifact is fabricated by this repo.
